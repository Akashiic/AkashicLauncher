# Marca da Forbidden Series

Arquivos gerados a partir do kit oficial da marca (recortados e reduzidos para uso no launcher):

| Arquivo | Uso |
|---|---|
| `logo-mark.png` | Símbolo (olho) — topo da coluna, tela de perfil, carregamento |
| `wordmark.png` | Nome "FORBIDDEN SERIES" em linha — topo da coluna |
| `logo.png` | Olho + nome empilhados — abertura |
| `patch-cover.jpg` | Miniatura do card de novidade (render da cena 3D) |

Ícones do app: `electron/assets/icon.png` (janela/barra de tarefas) e `electron/assets/tray.png` (bandeja).
Para trocar a marca, substitua estes arquivos mantendo os nomes.
